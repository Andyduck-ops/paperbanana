# GD-003: Snapshot Resume Correctness

## Golden Case Summary

| Field | Value |
|-------|-------|
| **ID** | GD-003 |
| **Title** | Snapshot Resume Correctness |
| **Intent** | A resumed session must continue from the correct stage boundary using intact prior state. |

## Expected Behavior

| Requirement | Status |
|-------------|--------|
| `stages_must_not_rerun`: [retriever, planner] | **PASS** |
| `stages_continued`: [stylist, visualizer, critic] | **PASS** |
| `resume_metadata_preserved`: true | **PASS** |

## Verification Analysis

**Location**: `internal/application/orchestrator/runner.go:291-322`

**Analysis**:

The `resumeTracker` method (lines 291-322) implements stage-skipping logic:

```go
    // ...validation...

    searchStages := domainagent.CanonicalPipeline()
    for index := len(searchStages) - 1; index >= 0; index-- {
        stage := searchStages[index]

            continue  // Skip incomplete stages

        // Found valid restore point

        // ...

    // ...
}
```

The `remainingPipeline` function (lines 384-391) computes stages after the restore point:

```go
func remainingPipeline(current domainagent.StageName, pipeline []domainagent.StageName) []domainagent.StageName {
    for index, stage := range pipeline {
        if stage == current {
            return append([]domainagent.StageName(nil), pipeline[index+1:]...)
        }
    }
    return nil
}
```

**Result**: Completed stages (retriever, planner) are correctly excluded from the remaining pipeline.

- `StageStates` cloned from snapshot (completed stage states)
- `FinalOutput` cloned from snapshot (planner output)

The `restoreCompletedStates` method (lines 325-370) rehydrates agent states:

```go
func (r *Runner) restoreCompletedStates(snapshot agentstate.Snapshot) error {
    completedStates := make(map[domainagent.StageName]domainagent.AgentState, len(snapshot.Session.StageStates)+1)
    for _, state := range snapshot.Session.StageStates {
        if state.Status != domainagent.StatusCompleted {
            continue
        }
        completedStates[state.Stage] = cloneAgentState(state)
    }
    // ...
    for _, stage := range r.pipeline {
        state, ok := completedStates[stage]
        if !ok {
            continue
        }
        stageAgent, ok := r.agents[stage]
        // ...
        if err := stageAgent.RestoreState(cloneAgentState(state)); err != nil {
            // error handling
        }
    }
    return nil
}
```

**Result**: All completed stage states are restored via `RestoreState()` on each agent.

## Conclusion

**GD-003: COMPLIANT**

The implementation correctly:

1. **Skips completed stages**: `remainingPipeline()` computes stages after the restore point, preventing re-execution of retriever and planner.

2. **Restores complete state**: `restoreCompletedStates()` calls `RestoreState()` on all completed stage agents, rehydrating their internal state.

3. **Preserves resume metadata**: `RestoreMetadata` is populated with `SnapshotVersion`, `RestoredFrom`, and `RestoredAt` in `newRestoredSessionTracker()`.

The codebase passes all verification criteria for GD-003.
